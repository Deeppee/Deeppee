Крипто-метрики режима рынка

Ежедневные и годовые значения ключевых индикаторов бычьего/медвежьего рынка с января 2023 по сегодня. Данные собраны из публичных API и агрегированы в один дашборд.

BTC цена и 200 DMA

Цена выше 200-дневной средней — типичный бычий режим; ниже — медвежий.

Bitcoin Dominance

Рост BTC.D часто = risk-off / капитал в BTC; падение = риск в альты.

Fear & Greed Index

0–24 extreme fear, 25–49 fear, 50–74 greed, 75–100 extreme greed.

Funding Rate (BTC perp, % за 8ч)

Сильно плюс = перегретые лонги; минус = перекос в шорты / страх.

MVRV

Рыночная капитализация / реализованная. >3.5 перегрев, <1 недооценка.

Exchange Netflow (7d avg, USD)

Плюс = приток на биржи (давление продаж); минус = отток / накопление.

Open Interest (OKX BTC swap, USD)

Недельный OI: рост с ценой усиливает тренд; рост при падении — шорт-давление.

US Spot BTC ETF Net Flows

Суммарный дневной нетто-поток по спотовым BTC ETF (с января 2024).

Кумулятивный поток показан линией на правой оси.
